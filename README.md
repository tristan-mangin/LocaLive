# LocaLive
A cross-platform social media app built with **Django REST Framework** (backend) and **React Native + Expo** (frontend).
Users can find live music locally based on their taste, location, and/or friends suggestions, as well as follow, interact with and rate performers — all backed by a secure REST API and modern mobile UX.

---

## Tech Stack

| Layer | Technologies |
|:------|:--------------|
| **Frontend** | React Native (Expo), TypeScript, Axios, React Navigation |
| **Backend** | Django 4 +, Django REST Framework, JWT Auth |
